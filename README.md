# 🐱 Tom and Jerry Chase Game

A fun **Java 2D chase game** inspired by **Tom and Jerry**, where Tom tries to catch Jerry within a limited time.  
The game includes obstacles that affect player speed, adding strategy and excitement to the gameplay.

---

## 🎮 Game Overview

In this game:

- **Tom** (the cat) must catch **Jerry** (the mouse) before the timer ends.
- The game runs with a **30-second countdown timer**.
- Several **grey rectangular boxes** are placed inside the game window.
- When:
  - **Tom crosses a grey box** → Tom’s speed decreases.
  - **Jerry crosses a grey box** → Jerry’s speed increases.
- If Tom catches Jerry within 30 seconds → **Tom Wins**
- Otherwise → **Jerry Wins**

## 🎯 Game Rules

1. The game starts with a **30-second timer**.
2. Tom chases Jerry around the game window.
3. Grey rectangular zones act as special speed areas:
   - Tom becomes slower.
   - Jerry becomes faster.
4. Tom must touch/catch Jerry before the timer reaches zero.
5. If the timer ends before Tom catches Jerry, Jerry wins the game.
